# domain/ — rules

- Pure business logic. No file system, no network, no database, no model calls, no environment variables, no current time read implicitly (pass `now` as an argument). Ids and random tokens come from callers.
- Imports allowed: the standard library, declared pure libraries (e.g. `pydantic` if added), and other `domain` modules. Nothing else from `rack_overflow` (`tests/unit/test_layering.py`).
- Every public function has unit tests in `tests/unit/test_<module>.py`.
- Before adding a function, check the responsibility map in `docs/architecture.md`. If the responsibility exists, reuse or extend it. If you add a cross-cutting responsibility, add it to the map.
- Errors derive from `errors.DomainError`.

## Modules

| Module | Owns |
|---|---|
| `errors.py` | `DomainError(ValueError)`, base of every module's error class; `NotFoundError` (unknown id or another user's row) |
| `vocabulary.py` | Allowed values of enumerated columns (`VARIABLE_TYPES`, `VARIABLE_SCOPES`, `CORE_QUANTITIES`, `EXERCISE_CATEGORIES`, `LOCATIONS`, `SESSION_LOCATIONS`, `SESSION_STATUSES`, `SET_TYPES`): stable English keys, turned into `CHECK` constraints by `storage/schema` |
| `timestamps.py` | Database timestamp text: `to_text(dt)` (aware only, UTC `YYYY-MM-DDTHH:MM:SSZ`, seconds), `from_text(text)` (aware UTC); `TimestampError`. Every timestamp column written from L1b on goes through it |
| `users.py` | `SINGLE_USER_ID = 1`, the one user of V1 (D-017); read when creating a device and by `rack migrate` for the seed (D-057) |
| `devices.py` | Device pairing and token rules (D-049): constants (`CODE_DIGITS`, `CODE_TTL`, `MAX_ATTEMPTS`, `TOKEN_BYTES`, `TOKEN_LENGTH`, `TOKEN_LIFETIME`, `RENEW_AFTER`, `NAME_MAX`), `DeviceError`, `PairingOutcome`, `DeviceState`, `validate_name`, `normalise_code`, `format_code`, `hash_secret` (SHA-256 hex), `looks_like_token`, `is_live`, `judge_match` (a code whose hash matched), `judge_miss` (outcome and remaining attempts after charging live codes), `state_of`, `token_valid`, `needs_renewal`. Draws no random value |
| `supervision.py` | `RestartPolicy` (1 s doubling to 300 s, reset after 60 s of uptime) and `next_delay(policy, previous_delay_s, uptime_s)` (D-051) |
| `backups.py` | Snapshot rules (D-045): `snapshot_name(now, existing)`, `parse_snapshot_time(name)`, `ordered(names)` (oldest first by time then rank, the only snapshot ordering), `newest(names)`, `is_due(latest, now)`, `expired(names, now, retention_days)` (never the newest, never a name that does not parse) |
| `text.py` | `normalise(text)` (NFKD, accents removed, casefold, `œ`/`æ` expanded, every non-alphanumeric run → one space) and `slug(text)` (spaces → `_`): the one text normalisation (search, aliases, name uniqueness, codes, enum keys; D-056) |
| `units.py` | Canonical integers ↔ user text (D-055): `kind_of_quantity`, `NUMERIC_KINDS`, `parse(kind, raw, *, scale)` (`UnitError.code`: `not_a_number`, `too_many_decimals`, `negative`, `too_large`, `bad_duration`), `format(kind, value, *, scale) -> Display(number_text, unit_key)`, `input_text` (text `parse` reads back: an input prefilled in display units), `input_unit_key` (unit shown in an input label), `compact_duration` (the compact form of targets, « 30 min », as a `CompactDuration(key, params)`; D-055 refinement). Unit keys only (`unit.kg`…), no symbol |
| `catalog.py` | Catalog rules (D-054): `Problem`, `CatalogError` (every problem of a form at once), `text_input` / `choice_input` / `raise_if` (the shared form-field validators, reused by `templates`); variables (`variable_draft`, `ValueInput`, `EnumValue`, `enum_values`, `retired_after` (removed keys stay retired in `VariableDraft.retired_keys`, never reused), `variable_code`, `variable_change`, `value_column`); exercises (`exercise_draft`, `name_taken`, `check_name` (error code `name_taken` by default; templates pass theirs), `known_spelling`, `with_known_spellings` (pattern and equipment of a draft in their first-seen spelling, used by the exercise service and the seed), `sort_key` (list order of names and labels), `default_fields`); fields (`FieldKind`, `core_kind`, `variable_kind`, `field_params` typed in display units, `check_field` on canonical values, shared with the seed, `cleared_for`, `FieldSource`, `check_measures`, `check_linked_measures` (a variable delete or scope change keeps a measure on every linked exercise, `variable_last_measure`)); aliases (`alias_draft`) |
| `templates.py` | Template rules (D-058, D-059), refusals as `CatalogError`: `template_draft` (name 1 to 60, location), `check_template_name` (`catalog.check_name` with `template_name_taken`, archived included), `menu_label` (1 to 40), `Target` (canonical, all optional, `is_empty`), `target` (typed in display units: reps « 10 » / « 8-10 » / « 8 à 10 », durations and distances through `units`), `check_target` (canonical rules, shared with the seed), `reps_text`, `MAX_SLOTS` / `check_slot_added`, `MAX_OPTIONS` / `check_option_added` (`option_taken`, `too_many_options`), `check_option_removed` (`last_option`), `SLOT_KINDS` |
| `ordering.py` | The one reordering rule (D-058) of fields, templates, slots and menu options: `UP`, `DOWN`, `DIRECTIONS`, `check_direction` (else `CatalogError` `direction` / `invalid_choice`), `moved(ids, item_id, direction) -> (ids, new index)` (swap with the neighbour, unchanged at an end) |
| `search.py` | Fuzzy ranking (D-056): `Candidate(id, name, aliases)`, `rank(query, candidates, *, limit, recent)`, `score` tiers (exact, prefix, token prefixes, initials without stop-words, substring, edit distance 1 from 4 letters / 2 from 7 on token prefixes), `prefix_distance` (bounded Levenshtein) |
| `sessions.py` | Session logging rules (D-061 to D-063, D-065): `SessionError(code)`; start (`local_start(now, tz)` → local date and IANA name, `default_location`, `matches_location` / `templates_for`, `PlanSlot`, `start_plan` → `StartPlan(rows, pending)`); plan (`RowRef`, `Item` (row or pending menu), `display_sequence` (template slots in order, pending menus, then other rows by position), `current_item` (requested, else the latest set's row, else the first), `following`); fields and prefill (`SessionField` (form name `reps` / `weight` / `duration` / `distance` / `var_<id>`, kind, params, source), `variable_field`, `SetFacts(type, values)`, `set_types(category)` (« Test RM » for strength), `prefill(position, today, last, target, fields)`, `settings_prefill`); steppers (`stepped(params, value, up / down)`: increment, floor 0, empty starts at one increment, off-grid snap; `step_values` on display texts); forms (`set_draft` (`required`, unit codes, `invalid_choice`, `too_long`, `empty_set` on field `set`), `setting_draft` (None = cleared), `raw_texts` (canonical → input texts)) |
| `indicators.py` | Indicators computed from facts, never stored (D-021, D-064), the module L5 extends: `RECORD_TYPES` (work, RM test), `LoggedSet` (type, core quantities, session id), `is_record(category, candidate, previous)` (dominance: no earlier counted set at least as good on every quantity; cardio distance and speed; intervals: the round lifting its session's count above every earlier session's; never during the first session of the exercise: a counted set of another session must exist, D-064 refinement), `records(category, ordered_sets, wanted)`, `Volume` and `volume(category, sets)` (Σ reps × load, reps, durations, distances, counted sets), `round_count` |
