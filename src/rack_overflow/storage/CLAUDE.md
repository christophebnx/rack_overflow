# storage/ — rules

- Everything that touches the disk lives here (or in a later outer layer). Business rules stay in `domain/`.
- Every write of a user or state file goes through `files.atomic_write` (bytes) or `files.atomic_produce` (a writer that creates the temp file, e.g. `VACUUM INTO`). Never `Path.write_text` / `open(..., "w")` on such a file.
- No partial state on failure: write the new file completely, then switch to it.
- Tests use `tmp_path` only.
- The database is opened only through `db.create_engine` (pragmas, `BEGIN IMMEDIATE`). Queries use SQLAlchemy Core on `schema` tables; SQL stays Postgres-compatible (D-016, D-046).
- Schema changes: edit `schema.py` **and** add a new revision in `migrations/versions/` (autogenerate, then review; literal value lists, no import of `schema` or `domain`). A committed migration is never edited.
- Errors derive from `errors.StorageError`.

## Modules

| Module | Owns |
|---|---|
| `files.py` | `atomic_produce(path, produce)`: unused temp name in the same folder, `produce(temp)`, fsync, `os.replace`, folder fsync (POSIX), temp removed on failure; `atomic_write(path, data)` built on it |
| `errors.py` | `StorageError`, `MigrationError`, `BackupError`, `CorruptDatabaseError(BackupError)`, `DeviceNameTakenError`, `NameTakenError` (catalog uniques), `SessionOpenError` (`uq_session_one_open`) |
| `db.py` | `create_engine(database_path)`: WAL, `foreign_keys`, `synchronous = SYNCHRONOUS` (tests: OFF), `busy_timeout`, `BEGIN IMMEDIATE` on every transaction; `guarded_write(connection, write, refusal)`: a write in a savepoint whose unique-constraint violation raises `refusal` (other integrity errors propagate), the one savepoint guard of every unique check |
| `schema.py` | `metadata` (naming convention) and one `Table` per table of brief section 7.2; unique indexes added after 0001 are `sa.Index(..., unique=True)` (no SQLite table rebuild) |
| `migrate.py` | `upgrade_to_head(engine)`, `current_revision(engine)`, `head_revision()`, `is_up_to_date(engine)`; Alembic configured in code; an unreadable database or unknown revision raises `MigrationError` |
| `migrations/` | Alembic `env.py`, `script.py.mako`, `versions/` (frozen revisions, `0001_initial_schema.py`, `0002_variable_decimal_scale_not_null.py`, `0003_template_slot_deleted_and_seed_keys.py`: `template_slot.deleted_at`, `exercise.seed_key` + unique index `(user_id, seed_key)`, unique index `template (user_id, name)`; `0004_session_exercise_exercise_index.py`: index `session_exercise (exercise_id)`, D-066) |
| `backup.py` | `check_integrity(database_path)` (bare `sqlite3` connection, no engine pragmas; the copy is checked read-only), `take_snapshot(database_path, backups_dir, now)` (`VACUUM INTO` through `atomic_produce`, copy checked before the rename; corrupt source → `CorruptDatabaseError`, nothing written), `list_snapshots(backups_dir)` (in `domain.backups.ordered` order), `prune(backups_dir, now, retention_days)`; every `OSError` becomes `BackupError` |
| `devices.py` | Device and pairing-code queries on a caller's `Connection`: `insert_device` (active name taken → `DeviceNameTakenError`: the one check of that rule), `insert_pairing_code`, `active_device_by_name`, `all_devices`, `revoke`, `codes_by_hash` (newest first, with the device's `revoked_at`, `token_hash`, `name`), `unused_codes` (of active unpaired devices), `add_attempt`, `mark_used` (only an unused code) and `set_token` (only an active unpaired device), both returning whether the row was written, `device_by_token_hash` (active only), `touch`. No rule decided here |
| `variables.py` | Variable queries on a caller's `Connection`: `insert` (code taken → `NameTakenError`), `update`, `get(user_id, id)`, `codes`, `list_all` (with `linked_count`), `set_archived`, `delete` (its `exercise_field` links first), `has_values` (any `set_value` / `exercise_setting` row, soft-deleted included), `used_enum_keys`, `linked_exercises`, `draft_of(row)` (row → `domain.catalog.VariableDraft`; enum values stored as JSON `[{key, label}]` then the retired keys as `{key, retired: true}`, absent values as SQL `NULL`) |
| `exercises.py` | Exercise, field and alias queries on a caller's `Connection`: `insert` (optional `seed_key`) / `update` (name taken → `NameTakenError`), `set_seed_key`, `ids_by_seed_key`, `unkeyed_by_name` (normalised name → id of unkeyed exercises; D-060), `get`, `list_all`, `names`, `set_archived`, `has_history`, `movement_patterns` / `equipments` (distinct, first-seen first), `search_candidates` (one query → `domain.search.Candidate`); fields `fields_of` (with the variable's columns), `fields_of_variable`, `params_of(row)`, `insert_field` (last position through `positions.next_position`; linked twice → `NameTakenError`), `update_field`, `delete_field`, `set_positions` (through `positions.set_positions`); aliases `aliases_of`, `insert_alias`, `delete_alias` |
| `templates.py` | Template, slot and menu-option queries on a caller's `Connection`: templates `insert` / `update` (name taken → `NameTakenError`), `get`, `list_all` (with the live `slot_count`), `names`, `active_ids`, `next_position` (after the last non-archived, through `positions.next_position`), `set_archived` (restore with a position); slots (live only: `deleted_at IS NULL`) `slots_of` (with the exercise's name, pattern, `archived_at`), `next_slot_position`, `insert_slot` (exercise or menu label in `movement_pattern`), `update_slot`, `soft_delete_slot`; options `options_of(slot_ids)`, `insert_option` (same exercise twice → `NameTakenError`), `delete_option`; `target_values` / `target_of` (row ↔ `domain.templates.Target`) |
| `positions.py` | `next_position(connection, position_column, *where)`: `max(position) + 1` of the matching rows (0 when none), the one computation of the position of an appended row; `set_positions(connection, table, ids)`: `position = index` for each id, the one writer of positions after a move or a removal (fields, templates, slots, options) |
| `app_settings.py` | `get(connection, user_id, key)`, `put(connection, user_id, key, value)` (insert or update): per-user settings (`seed.version`, later the RM formula) |
| `seed.py` | `load_exercises(package, name)` and `load_templates(package, name)`: the packaged seed data `seed_data/exercises.json` and `seed_data/templates.json` (French data, not code; read through `importlib.resources`); exercises are a list of `{key, name, category, movement_pattern, equipment, location, fields: [{quantity, required, increment | discrete_values}], aliases}` in canonical integers (`key`: stable ASCII slug, never changed), templates a list of `{name, location, slots: [{exercise: key} | {menu: label, options: [key, …]}, target]}`; unreadable or malformed → `StorageError` (D-057, D-060) |
| `sessions.py` | Session queries on a caller's `Connection` (D-061 to D-066), no rule: sessions `insert_session` (open; another open session → `SessionOpenError` through `db.guarded_write`), `get_session` / `open_session` / `latest_session` (non-deleted), `close_session` (only when open); rows `insert_session_exercise` (position through `positions.next_position`), `session_exercises` (with the exercise's name, category, equipment, `exercise_archived_at`), `set_session_exercise_exercise`, `has_facts` (any set, deleted included, or setting); sets `insert_set`, `insert_set_values`, `sets_of` (live), `values_of`, `get_set` (live set of a non-deleted session, with `session_id`, `exercise_id`, `status`), `update_set`, `replace_set_values`, `soft_delete_set`; per exercise (index of 0004) `last_performance` (live sets of the latest other session holding one), `last_settings` (latest value per variable), `settings_of`, `upsert_settings` (None deletes a cleared setting), `record_history` (live work / RM-test sets by `(completed_at, id)` with `session_id`), `recent_exercise_ids`; `CORE_COLUMNS` (quantity → `set_entry` column). Integers go to `value_int`, text (enum keys, text) to `value_text` |
