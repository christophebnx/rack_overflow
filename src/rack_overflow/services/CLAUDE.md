# services/ — rules

- Business operations: each public function is one use case (one transaction when it touches the database), callable from the CLI, the web routes and later a JSON API.
- Imports allowed: the standard library, third-party libraries, `domain` and `storage` (`tests/unit/test_layering.py`). Never `web`, `cli` or `config`: values (paths, `now`, settings fields) are passed in.
- No clock or environment read implicitly: `now` comes from the caller.
- Business rules stay in `domain/`; disk and SQL stay in `storage/`. A service orchestrates them.
- Every public function has tests (`tests/unit/` or `tests/integration/` when it needs a database).

## Modules

| Module | Owns |
|---|---|
| `backups.py` | `backup_now(database_path, backups_dir, now, retention_days)` (snapshot, then prune) and `backup_if_due(...)` (only when the newest snapshot is ≥ 24 h old) |
| `export.py` | `export(engine, fmt, now, app_version)` → `ExportFile(file_name, media_type, data, rows)` (D-072 to D-074): `FORMATS` (`json`, `csv`; else `ExportError("unknown_format")`), the whole database read in one transaction through `storage/export.dump`, encoded by `domain/export`; `MEDIA_TYPES`. Shared by `rack export` and `GET /api/export` |
| `devices.py` | Device operations (D-049), one transaction each: `add_device` (name validated; unpaired device + pairing code, a taken active name is the storage `DeviceNameTakenError` turned into `DeviceError`; returns the code in clear once), `list_devices`, `revoke_device`, `pair` (match → `judge_match`, then `mark_used` and `set_token` in a savepoint: either refuses → rolled back, `code_expired`; miss → attempt charged to every live code, `judge_miss`; malformed input charges nothing), `authenticate` (token shape checked before any database access; `last_seen_at` refreshed at most once an hour). Draws the random code and token (`secrets`) |
| `variables.py` | Variable operations (D-054), one transaction each, `user_id` passed in: `create(VariableForm)` (code from `domain.catalog.variable_code`), `update` (`variable_change`: frozen type / scope / scale once values exist, used enum keys kept, removed keys retired; scope change refused when it leaves a linked exercise without measure; field parameters the new kind refuses are cleared on every link), `set_archived(now | None)`, `delete` (only without values, else `variable_in_use`; not when it is a linked exercise's last measure, `variable_last_measure`), `get_detail` (`VariableDetail`: links, `has_values`, `used_enum_keys`), `list_variables`. Unknown or foreign id → `domain.errors.NotFoundError` |
| `exercises.py` | Exercise operations (D-054, D-056), one transaction each: `create(ExerciseForm)` (name unique after normalisation, pattern / equipment in their first-seen spelling, default fields of the category), `update`, `set_archived`, `get_detail` (`ExerciseDetail`: fields as `FieldView` with kind and parameters, read by `field_views(connection, exercise_id)`, also used by `sessions`; aliases, `has_history`, addable core quantities and non-archived variables), `list_exercises`, `search_exercises` (`domain.search.rank`), `suggestions`, `add_field` (core quantity or variable; `already_linked`), `update_field(FieldForm)` (display units parsed by `domain.catalog.field_params`), `remove_field` (`last_measure`; stored values kept), `move_field(up | down)` (`domain.ordering.moved`; `UP` / `DOWN` re-exported), `add_alias`, `remove_alias` |
| `templates.py` | Template operations (D-058, D-059), one transaction each, `user_id` passed in: `create(TemplateForm)` (last; `template_name_taken`, also from the `NameTakenError` race), `update`, `set_archived(now | None)` (restore → last), `move` (among non-archived), `list_templates`, `get_detail` (`TemplateDetail`: live `SlotView`s with `ExerciseRef` / label, `OptionView`s, `Target`, `skipped`; non-archived `available` exercises, `groups` / `option_groups` (by movement pattern, the menu's own first; `exercise_groups`), label suggestions), `add_slot` (kind `exercise` or `menu` with its first exercise; `too_many_slots`, `exercise_unavailable`), `update_slot(SlotForm)` (fixed: exercise, the current one kept even archived; menu: label; both: target), `move_slot`, `remove_slot(now)` (soft delete, renumber), `add_option` (`option_taken`, `too_many_options`), `move_option`, `remove_option` (`last_option`); `slots_for_session(connection, template_id)` is the one live-slot reader (template pages and `sessions`). Unknown, foreign or removed ids → `NotFoundError` |
| `seed.py` | `seed_catalog(engine, user_id, steps=STEPS) -> SeedReport(exercises, templates)` (D-057, D-060): steps above `app_setting` `seed.version` run in one transaction, then the version is stored; step 1 attaches seed keys to same-name unkeyed exercises (`_attach_keys`, adoption) and inserts the seed exercises with their `seed_key` through the domain validators (`exercise_draft`, `check_field`, `check_measures`, `alias_draft`), skipping a normalised name that exists; step 2 runs the same key attachment (L2 databases), then inserts the four templates (`template_draft`, `menu_label`, `check_target`, `check_option_added`), skipping a taken normalised name and dropping unresolved keys (a slot left without exercise is not created); malformed items or an unreadable stored version → `StorageError`. Called by `rack migrate` |
| `sessions.py` | Session logging operations (D-061 to D-066), one transaction each, `user_id`, `now` and the `tzinfo` passed in: `start_page` (`StartPage`: open session with counts, else default location, templates with `last_used`), `start` (an open session is returned instead of a new one, also after a `SessionOpenError` race; `template_unavailable`), `show` (`SessionView`: plan items, `RowCard`s, pending `MenuView`s, current item from `?exercice` / `?menu`, `block` = the current `RowView` with fields, settings (stored over prefill), sets with ⭐, next-set `FormState`, change options; or `SummaryView` when closed), `pick` (menu option or added exercise; `slot_already_picked`, `exercise_unavailable`), `change_exercise` (`exercise_has_sets`), `search_exercises` (`SearchResults`: recent then others, or ranked), `set_form` (stepper, no write), `confirm_set` (`Confirmed`; missing settings written from the server prefill), `locate_set`, `update_set` / `delete_set` / `save_settings` (`require_open=False` for L5 history: they answer the closed session's `SummaryView`, the corrected row kept even without a live set), `block`, `detail` (closed session as stored, re-render after a refused correction), `info` (a session's own attributes), `delete_session` (soft, open or closed, D-067), `unlogged_count`, `close` (no-op when closed); `SummaryView.exercise_count` (rows with a live set: the « Exercices » tile); `RowFacts` (fields, settings, sets, `settings_texts`, `set_texts`, `set`) is shared by `RowView` and `SummaryRow` (row id, settings, setting fields, types: the L5 detail); helpers reused by `progress` / `history`: `exercise_fields`, `set_views`, `session_info`, `logged_set`. Closed session writes → `SessionError("session_closed")`; unknown, foreign or deleted ids → `NotFoundError` |
| `history.py` | History operations (D-067, D-070): `history_page(engine, user_id, before_id)` → `HistoryPage` (20 `HistoryItem`s per keyset page grouped in `MonthGroup`s, `continues_month`, `next_before`; counted sets and load volume through `domain.indicators.volume`), `consistency(engine, user_id, today)` → `Consistency` (12 `WeekCount`s, `average_tenths`, `this_week`) |
| `progress.py` | Progress operations (D-068, D-069): `RM_FORMULA_KEY`, `formula`, `set_formula` (`invalid_choice`), `progress_index` (`ProgressItem`s), `exercise_progress` → `ProgressView` (last performance of any session, `RmView`, main series, `DayTable`, `Bests`, formula), `chart_data` → `ChartData`, `rm_view`, `add_measured_rm` → `RmSaved` (strength only, `rm_not_strength`; `domain.progress.rm_draft`), `delete_measured_rm` → `RmDeleted` (soft; the entry listed after it, for the focus). Everything recomputed from facts on each read; unknown or foreign ids → `NotFoundError` |
